## Shared names
- `MoreGrid` (on base, src/features/look/MoreGrid.tsx, exported from look/index.ts): `<MoreGrid label testId? step?=4 moreLabel?>{cards}</MoreGrid>`. 2-column grid, Show N more / Show less. Every former swipe card row (Carousel, .dc-posters, .fy-vids, .cm-media rows, .mv-ccard rows, .dc-vrow) becomes a MoreGrid; cards lose fixed widths (`width:auto`). Non-card swipe rows (Today hero slides, Family faces row, memories strip) get a stacked or grid layout instead (no horizontal scroll).
- Tab colour tokens (E): App sets `data-tab="today|health|discover|family|safety"` on `.bt`; v13.css defines per tab `--tab-bg` (page ground top), `--tab-bg2` (ground below 320 px), `--tab-glow` (header glow colour), `--tab-accent` (text-safe accent, 4.5:1 on --tab-bg), `--tab-accent-soft` (chip fill). Values from board S25Tabs: today #FBF1DE/#F6EEDD/#F4C66B/#8A4F05/#FDE7BF; health #FBEDEB/#F8EEEC/#F2A3AC/#9C2A3A/#F9D9DD; family #EAF3EC/#EEF3EE/#9CD3B4/#155239/#D3EBDD; discover #E9EEF9/#ECF0F7/#A8C1F2/#1D47A0/#D6E2FA; safety #E6F2F1/#EAF3F2/#8FCFC8/#0B5C55/#CDEAE6. Dark mode: same hues at low strength, defined by E. Red stays for SOS only. Other lanes use `var(--tab-accent)` for section accents and may not hard-code tab hues.
- Depth token (E): `--depth-card: 0 1px 2px rgba(40,30,10,.06), 0 12px 26px -14px rgba(40,30,10,.32)` and class `.card-depth` (gradient top edge + shadow). D applies it to Family feature cards; B/C may use it on feature cards.
- Health library route (A1): moves to `#health/library` and `#health/library/<key>`; `articleHref()` in medline.ts returns the new hash. B adds the route lines in screens/Health.tsx: `if (hash.startsWith('#health/library')) return <Library />` (lazy import from features/health/library/Library) and the Browse tile "Health library". The old `#discover/learn/library...` hash redirects (C: learn/Screen.tsx replaces it with the new hash).
- Encyclopedia data (A1): `src/data/medlib/topics.json` = `{ version, source, topics: Topic[] }`, `Topic = { id, title, aka: string[], body: 'heart'|'lungs'|'infections'|'sugar'|'kidneys'|'mind'|'bones'|'children'|'firstaid', ph?: boolean, season?: 'rainy'|'dry'|null, short: string[3], goNow: string[], sections: {heading, text}[], videos: {id, title, source}[], links: {medlineplus?, wikipedia?, tagalog?}, picture?: {file, credit, licence, href} }`. Plain words, short sentences; Opus reviews every health line. Loaded lazily (own chunk), works offline (precached).
- Full library (A2): `FullLibraryCard` (A1 renders it once on the library home) and `searchFullLibrary(q): Promise<{title, snippet, key}[]>` (empty when not downloaded) that A1's search calls after its own results. Every article view shows mdwiki credit + CC BY-SA link.
