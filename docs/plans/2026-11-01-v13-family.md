## 2. Pure logic (TDD; vitest files beside each)
### `personFocus.ts`
```ts
export type Focus = { kind: 'unwell'|'missed'|'questions'|'due'|'nocheck'|'ok'|'nothing'; tint: Tint; line: string; body: string; action: { label: string; kind: 'call'|'mark'|'answer'|'message'|'open' } | null }
export function personFocus(p: Pick<FamilyPerson,'id'|'name'|'isMe'|'phone'>, d: {
  unwell: boolean            // unseen mood_unwell AlertRow for p
  missed: DoseLine[]         // todayView(...).doses with word 'Missed'
  due: DoseLine[]            // word 'Due now'
  later: number              // word 'Later' count
  asks: ReviewAsk[]          // reviewAsks(...) for p
  checkIn: string | undefined// useCheckIns()[p.id]
  canMark: boolean           // p.id in useCarerIds() (writer) and not acting
  now: Date }): Focus
```
Priority (first match wins): unwell → missed → asks.length → due → `!checkInLabel(checkIn, now).ok` → ok.
Cases: (1) unwell beats everything: tint red, line `Not feeling well`, action call when `dial(phone)` else message. (2) one missed: line `Missed a medicine`, body `Nasal spray was due 8:00 AM, 12 h ago. 2 later doses not marked yet.` (`slotAgo` from CarerCards), action `Mark taken` when canMark else `Open`. (3) two missed: line `Missed 2 medicines`. (4) 5 asks: line `5 questions waiting`, body `"Still taking Cefixime?" and 4 more, asked 11 days ago.` action `Answer`. (5) 1 ask: `"Still taking X?" asked yesterday.` (6) due now 4: line `4 medicines at 8:00` (clock of first), body `0 of 4 taken today.`, action `Open`. (7) no check-in, not me: tint none, line `No check-in today`, body `lastCheckInWords(...)`, action message when phone else open. (8) checked in: line `OK 7:40 AM`, body `Nothing waiting.`, action open. (9) isMe never gets mark/answer/message; `canMark` false → never `mark`. (10) `now` fixed in every case (ML-32).
`sortByFocus(cards)`: red first, then amber, then none; ties keep roster order. Test: [ok, missed, asks] → [missed, asks, ok].

### `weekSeries.ts`
```ts
export const DAYS = 7
export function dayKeys(now: Date): string[]              // 7 local YYYY-MM-DD ending today (dayOf from health/meds)
export function bpSeries(readings: Reading[], ids: string[], now: Date): Series[]        // per person: mean systolic per day, null gaps
export function stepSeries(acts: Activity[], ids: string[], now: Date): Series[]          // kind 'steps', sum per day
export function doseSeries(meds: Medication[], takes: MedTaken[], ids: string[], now: Date): Series[] // taken/due % per day via slotsFor+matchDoses
export type Series = { personId: string; points: (number|null)[]; latest: number|null; empty: boolean }
export function legendWord(metric: 'bp'|'steps'|'meds', s: Series, doctor?: Range|null): string // `148 high` (bpPairLevel on systolic only → BP_WORDS), `3,120`, `80%`, `no readings`
export const BAND = { bp: [90, 120], steps: null, meds: [80, 100] } // healthy band from GUIDE.bp_systolic (ranges.ts), not literals
```
Cases: 7 keys end today; two readings same day average (120,130→125); other person ignored; a reading 8 days old ignored; steps 2 rows one day sum; dose % = taken/(taken+pending+skipped), day with no slots → null; all-null → `empty: true`; `legendWord('bp', {latest: null})` → `no readings`.
