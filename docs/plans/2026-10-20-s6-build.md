# S6 Build: scheduled medicines, Today, weather, safety localisation, tracking

**Goal:** Every imported prescription becomes an editable scheduled medicine that reminds and can be marked taken in
one tap; Today leads with the next dose and the person's own week (KPIs); weather lives in one screen with an action line; Safety
follows the member's place; habit events are measurable.

**Sources of truth:** docs/session-6/PART-3.md (IA, rules), PART-2.md (events, targets), AUDIT.md (gaps, file:line),
mockups Artifact (link in PART-4.md; screen ids `data-id`), v6 tokens (unchanged).

**Tech stack:** unchanged (React 19, TypeScript, Vite, Dexie 4, Supabase JS, Capacitor 8, Vitest, Playwright).

**Gates for every lane:**
- `npx tsc --noEmit` exit 0; `npm test` green; `npm run e2e` green.
- 390x844 light AND dark screenshots of every touched screen, reviewed by the orchestrator (Opus) before merge.
- `e2e/no-sideways-scroll.spec.ts` green; new `e2e/tabbar-overlap.spec.ts` green (last element of every tab scrolls
  fully above the tab bar).
- No medicine names or health values in notifications or event payloads (B-7).
- SQL: every migration has a down script and passes `supabase/tests/records_rehearsal.sql` plus new
  `supabase/tests/medications_rehearsal.sql` on a branch DB before Lloyd applies it.
- Production steps (apply migration, deploy edge function, n8n change, APK release) go to Lloyd as one PowerShell 5.1
  block that stops at the first failure.
