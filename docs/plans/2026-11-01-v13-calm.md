| Mood | `FEELINGS`, `logFeeling`, `feelingToast` from `today/actions` (import only); labels stay the app's `Great / OK / Not great / Unwell` (board says Good/Okay/Low: Today, QuickLog and StormCard all use the app labels, one vocabulary). Links only = licence-clean; `<audio>` would add a player, state and stream-URL maintenance for no asked-for value. |

Rows from `hotlines.json` where `group === 'Mental health'`, `zone === 'ph'`, `status !== 'UNVERIFIED'` (today: `hl-ncmh`, `hl-ncmh-globe`, `hl-ncmh-smart`, all `LISTED`, source ncmh.gov.ph 2026-10-20).
