## 7. Risks

- **Leaflet in jsdom:** map mounts must be lazy (`import('leaflet')` inside `render`) and guarded (`typeof window.matchMedia`,
  no `getBoundingClientRect` assumptions); vitest asserts the placeholder, Playwright asserts the real map with the tile
  host stubbed (`page.route('https://tile.openstreetmap.org/**')`). Offline tiles are out of scope (lane M).
- **Four Leaflet mounts on four pages** add no bundle (already a chunk) but each is a network user: `NearView` wrapper on
  every map; the World map at zoom 4 fetches ~12 tiles.
- **Honesty vs boards:** the boards show rich sample data; the real screens will look emptier (two pinned places, one hazard
  zone). The report must show this beside the boards rather than fill it.
- **SOS regression:** `SosButton`/`SosScreen`/`useHold` untouched; only the surrounding markup moves. e2e case 2 proves it.
- **Old-spec churn:** S2 breaks `safety.spec`, `firstaid.spec`, `weather.spec`, `s5-alerts`, `look.spec` until S10; the per-step
  gate is tsc + vitest, so the branch is never red on committed vitest, but Playwright on those files is red between S2 and S10.
- **`hasOwnHeader` hook:** F0-D's `subpage-header.spec` lists no `#safety/world`; the top bar stays on World by design.
- **Windy on mobile data:** `navigator.connection` is Chromium/Android only; iOS falls back to "unknown" (iframe loads). Note it in the UI copy.
- **Flags via localStorage** are per phone and dev-only; a real rollout needs a kv or server flag (lane G/A). One-line shortcut comment in `flags.ts`.
- **Vibration/WebAudio** need a user gesture: created on the Start tap only; Playwright stubs `navigator.vibrate`.
- **PAR polygon** is the published approximate ring, labelled "approx."; not an official boundary.
