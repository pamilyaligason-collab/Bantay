# Session 6: default Quick dial numbers (proposed)

Prepared 2026-10-20 for PART-3 section 4.1. Data file: `hotlines-proposed.json` (same shape as
`src/data/safety/hotlines.json`, plus `zone`). Public agency numbers only.

**Status meaning**
- CONFIRMED: source page read live (2026-10-17).
- LISTED: the official source's own text, seen through web search on 2026-10-20; the page itself could not be opened
  from the cloud session (proxy blocks .gov.ph and most official sites).
- UNVERIFIED: secondary or conflicting sources. Shown with a "check" mark; confirm by opening the source or calling
  before release (build lane M5 gate).

**Rule:** only one local set shows, chosen by location (PART-3 4.1). National shows in the Philippines; OFW and
teleconsult show everywhere.

## Known conflicts to resolve before release
- Cebu City: reports in Aug 2026 say the city dropped its own 911; national 911 routes via Manila first. Old 166/160 lines may be dead.
- Davao: some local 911 calls reportedly misrouted (Jan 2026). Fire district lines are for inquiries; for a fire dial 911.
- Tagbilaran: city 911 serves residents only; police numbers differ across 5 listings; no Bohol Red Cross number found.
- General Santos: City Hospital has 3 different numbers in sources; BFP regional list shows 551-1160 (likely 552-1160).
- Manila: DRRM landline differs across 3 sources; MPD number only from a third-party site; Ospital ng Maynila last digits differ; no Manila BFP emergency line found (use 911).
- Hospitals: no dedicated ER lines found; numbers are switchboards ("ask for ER").
- DOH 1555: listed by DOH, began as a COVID line; scope today unclear.
- NCMH: Smart/TNT number changed (0919-057-1553 current; 0908-639-2672 older, left out).
- OFW: DFA help for OFWs moved to DMW in July 2023 (call 1348); DMW WhatsApp numbers came from crisis news and may be temporary.
- Teleconsult: KonsultaMD number only from 2020 news; Medgate has an older 8424-1747 on one page.
- Texas: no public TDEM info line; 311 is city-specific (Houston shown as an example).
