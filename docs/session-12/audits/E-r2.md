3. [minor] (ML-12 copy) 'On. Family alerts can reach you when Bantay is closed.' still does not depend on the server having FIREBASE_SERVICE_ACCOUNT_B64. If APK 2.4.0 ships before the secret is set, the claim succeeds and the row says On, but dose-watch sends no FCM. The round 1 major named this case. The lane brief only requires permission + token + claim, so this is a release-order gate: set the secret and deploy before the APK is distributed. It also stays 'ready' after the server deletes the token (404/410, 5 failures, or 60-day prune) until the next app open re-claims it.
